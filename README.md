# Odin Recipes

This is the first project from The Odin Project's Foundations curriculum,
completed at the end of the HTML Foundations section.

## About

A multi-page recipe website built using only HTML. The project features
three authentic Kenyan recipes representing both coastal Swahili cuisine
and upcountry Central Highlands cooking traditions.

## Recipes Included

- **Pilau** — A richly spiced Swahili coastal rice dish with Arab and Indian roots
- **Nyama Choma** — Kenya's iconic charcoal-grilled goat meat served with kachumbari
- **Githeri** — A hearty Kikuyu upcountry stew of maize and red kidney beans

## Skills Demonstrated

- HTML document structure and boilerplate
- Linking between multiple HTML pages using relative paths
- Unordered and ordered lists
- Embedding images with alt text
- Semantic heading hierarchy
- Git workflow with meaningful commit messages
